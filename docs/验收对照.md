## 2. 前端必须是 Vue3

- `frontend/package.json`：`vue ^3.5.13`、`vue-router ^4.5.0`、`pinia ^2.2.6`
- `frontend/src/main.js`：`createApp(App)` + Pinia + Router
- 页面：`frontend/src/views/` 共 17 个 `.vue` 页面（登录、工作台、课程、教学班、章节、成绩册、签到、通知等）
- 构建：Vite 6，产物输出到 `frontend/dist/`

## 3. 使用浏览器渲染和显示

- 前端是标准 Web SPA，由 Vite 构建成 `index.html + JS + CSS`
- Python 后端通过 `backend/http/static.py` 托管 `frontend/dist/`，浏览器访问 `http://127.0.0.1:端口`
- 纯浏览器模式：

```powershell
.\.venv\Scripts\python.exe run.py --browser
```

## 4. 使用 WebView

- 桌面窗口用 `pywebview` 创建，强制使用 Windows WebView2（Edge Chromium 内核）：

```python
window = webview.create_window("EduFlow 教务系统 v1.0.0", url=None, ...)
window.load_url(url)
webview.start(_load_app, gui="edgechromium", debug=args.debug)
```

- 位置：`run.py` 第 143、166、188 行
- WebView 里加载的仍然是同一个 Vue3 页面，所以「浏览器渲染」和「WebView 封装」是同一套前端，两种外壳：
  - `run.py`：WebView2 桌面窗口
  - `run.py --browser`：系统浏览器

## 5. 纯代码 5000 行以上（不含依赖库和前端）

只统计 **后端 Python**（`backend/` 62 个文件 + `run.py`），不含前端、`.venv`、`node_modules`、构建产物：

| 统计口径 | 行数 |
|---|---:|
| 物理行（含空行/注释） | 10,464 |
| 非空行 | 8,773 |
| 去掉空行、`#` 注释和 docstring 的可执行代码行 | **7,886** |

即使按最严格的口径（去掉注释和文档字符串），后端仍有 **7,886 行**，超过 5000 行要求。

复算命令：

```powershell
cd D:\EduFlow
@'
import ast, io, tokenize
from pathlib import Path
ROOT = Path(r"D:\EduFlow")
files = [p for p in ROOT.rglob("*.py") if "backend" in p.parts and ".venv" not in p.parts and "__pycache__" not in p.parts]
files.append(ROOT / "run.py")
code = docs = 0
for p in files:
    text = p.read_text(encoding="utf-8-sig")
    tree = ast.parse(text)
    ds = set()
    for node in ast.walk(tree):
        if isinstance(node, (ast.Module, ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)):
            body = getattr(node, "body", [])
            if body and isinstance(body[0], ast.Expr) and isinstance(body[0].value, ast.Constant) and isinstance(body[0].value.value, str):
                ds.update(range(body[0].lineno, (body[0].end_lineno or body[0].lineno) + 1))
    hit = {t.start[0] for t in tokenize.generate_tokens(io.StringIO(text).readline)
           if t.type not in {tokenize.COMMENT, tokenize.NL, tokenize.NEWLINE, tokenize.INDENT, tokenize.DEDENT, tokenize.ENCODING, tokenize.ENDMARKER}}
    code += len(hit)
    docs += len(ds & hit)
print("代码行:", code - docs)
'@ | .\.venv\Scripts\python.exe -
```
